### HOW TO ADAPT PORTRAITS TO ADVISOR SIZE ###
1) Go to remove.bg
2) Upload leader portrait (you can just copy-paste it into the browser window)
3) Download preview image
4) Resize to 50 pixels, Bicubic resampling (NOT Bicubic (Smooth) as this will blur the image)
5) Paste into empty_advisor.dds Layer 3
6) Magic wand the empty space on Layer 4
7) Delete that selection on Layer 3)
8) Use the eraser to trim the portrait spillover on the left, have just the edge visible (if you see the paper background, you removed too much)
9) Save in the correct folder
10) Add to 00_portraits.txt in the portraits folder
11) [Optional] If it's a generic leader, don't forget to add correct pathing in interface/IR_portraits.gfx
12) Done!
